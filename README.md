# 📊 Sales Data Analysis

## 📌 Project Overview

This project focuses on analyzing **Sales Data** to identify sales trends, customer performance, product performance, and overall business insights.

The project uses **SQL, Python, Excel, and Power BI** to clean, analyze, visualize, and present the data in an interactive dashboard.

---

## 🎯 Project Objectives

* Analyze overall sales performance
* Identify top-performing products
* Analyze sales by region and category
* Find monthly and yearly sales trends
* Identify high-value customers
* Calculate important business KPIs
* Create an interactive Power BI dashboard
* Generate meaningful insights for business decision-making

---

## 🛠️ Tools & Technologies

* **Excel** — Data inspection and initial analysis
* **MySQL** — Data storage and SQL queries
* **Python** — Data cleaning and analysis
* **Pandas** — Data manipulation
* **Power BI** — Data visualization and dashboard
* **DAX** — KPI and calculated measures
* **GitHub** — Project documentation and version control

---

## 🔄 Project Workflow

```text
Raw Sales Data
      ↓
    Excel
      ↓
    MySQL
      ↓
SQL Data Cleaning & Filtering
      ↓
   Power BI
      ↓
Interactive Sales Dashboard
      ↓
Business Insights
```

## 📈 Key KPIs

The dashboard includes important sales KPIs such as:
